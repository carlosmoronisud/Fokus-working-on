# Fokus

**Fokus** é uma aplicação web projetada para ajudar a melhorar a produtividade e o foco durante o trabalho ou estudos. O projeto foi desenvolvido como parte de um exercício na plataforma Alura, com o objetivo de criar uma ferramenta simples de timer com funcionalidades de foco, descanso curto e longo, além de um controle para ativar música durante os períodos de trabalho.

## Visão Geral

O Fokus tem como principal funcionalidade permitir que o usuário escolha entre períodos de foco, descanso curto e descanso longo. A interface simples e intuitiva permite iniciar, pausar e alternar entre os diferentes tipos de intervalos, oferecendo também a opção de ativar uma música ambiente para ajudar na concentração.

## Funcionalidades

- **Foco:** Inicie um período de foco onde o timer conta o tempo dedicado exclusivamente ao trabalho ou estudo.
- **Descanso Curto:** Após o período de foco, você pode optar por um intervalo curto para descanso.
- **Descanso Longo:** Uma opção de intervalo mais longo para recarregar as energias entre sessões de foco.
- **Música Ambiente:** Alternar a opção para tocar música enquanto você trabalha ou estuda.
- **Controle de Timer:** Iniciar e pausar o timer com um simples clique de botão.

## Tecnologias Utilizadas

- **HTML5:** Estruturação da página e conteúdo semântico.
- **CSS3:** Estilização e responsividade para tornar a aplicação agradável em qualquer dispositivo.
- **JavaScript:** Para a lógica de contagem do tempo e interatividade da aplicação.
- **Google Fonts:** Para fontes personalizadas, oferecendo uma leitura agradável.
- **Meyer Reset:** Para padronizar o estilo básico entre navegadores.
